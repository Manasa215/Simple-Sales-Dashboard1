# Deployment and Rollback Documentation
## 1. Project Name
Simple Sales Dashboard Design
## 2. Project Overview
This project uses Microsoft Excel to analyze sales performance by month, product category, region, customer segment, and payment method.
The dashboard presents key performance indicators (KPIs) and charts to help users understand sales and profit trends.
## 3. Tools Used
- Microsoft Excel
- GitHub for version control and project sharing
## 4. Deployment / Publishing Approach
This project is an Excel-based dashboard and does not require a web server or application deployment.
Steps to publish the project:
1. Save the completed workbook as `Sales_Dashboard_Enhanced.xlsx`.
2. Verify that the charts, formulas, and filters work correctly in Microsoft Excel.
3. Upload the Excel workbook to the public GitHub repository.
4. Upload the `How_to_Read_Sales_Dashboard.pdf` guide.
5. Maintain project documentation in the repository's README files.
6. Share the public repository link with reviewers.
## 5. Validation
Before submission, verify the following:
- The dashboard opens successfully in Excel.
- KPI calculations and charts display correctly.
- Dataset filters work as expected.
- The one-page guide explains the dashboard.
- The GitHub repository is publicly accessible.
## 6. Rollback Plan
If an updated workbook causes errors or affects the dashboard:
1. Keep a backup of the last working workbook.
2. Open the GitHub repository and navigate to the commit history.
3. Identify the last working version of the project.
4. Download that version or revert the faulty commit.
5. Restore the working workbook and verify the charts, formulas, and filters.
6. Document the issue and the restoration steps.

## 7. Expected Outcome
The project is available through GitHub with its Excel workbook, dashboard guide, and supporting documentation.
